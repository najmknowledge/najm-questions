# NAJM daily questions

One file per day in `days/YYYY-MM-DD.json` (and each month's question packs in `packs/YYYY-MM.json`; every pack, written or planned, is in `packs/library/` and `packs/schedule.json`), read by the NAJM app from https://najmknowledge.github.io/najm-questions/days/.
Published with `npm run questions:publish` — edit the files in the app project, not here.
